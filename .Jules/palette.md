## 2025-05-18 - Drag-and-Drop Dropzone Accessibility
**Learning:** File dropzones with `role="button"` need explicit `aria-label`, native drag-over visual feedback (`.is-dragging`), and support for both `Enter` and `Space` key triggers to be fully accessible for keyboard and screen reader users.
**Action:** Use the centralized `Dropzone` component for file uploads across forms in this app.
